## 数据与恢复

设置页展示实际数据目录，并提供“打开数据目录”。它使用 Electron 的 `app.getPath("userData")`，不要在开发时猜测目录并覆盖现有数据。

- 正式运行任务文件：`data.json`；开发运行：`data-dev.json`。
- 窗口位置与尺寸：`window-state.json`。
- 滚动备份：`backups/` 或 `backups-dev/`，通常保留最近 10 份。完成、删除、恢复等操作前备份；运行期间每五分钟、正常退出前备份。清理失败时保留旧备份。
- 迁移、导入或损坏原文件的保护副本：`safety/`，不随滚动备份清理。
- JSON 包含待办、完成记录、顺序、ID、日期、回收站、最近完成撤销记录及应用保存的设置。窗口几何位置和系统开机启动选项不在任务 JSON 内。
- 导入是替换，需在应用中确认；导入前保留当前数据。无效格式不会覆盖当前任务。主文件损坏时优先恢复有效本地备份；没有可用备份时提供选择外部备份、打开目录或退出，不静默清空。
- 原子写入先写临时文件、同步并替换主文件；失败时保留原数据并显示错误。这不等于已经完成断电或真实硬盘故障验证。

## 未完成的原生验收

当前缺少 `node_modules/electron/dist/electron.exe`。下载运行时的提权请求被自动审批拒绝，返回原因是审批服务用量限制。没有绕过拒绝、伪造运行时或把源码编译当作桌面构建成功。

恢复下载审批后，需要依次完成：

1. 安装 Electron 运行时，在独立 `YANQIAN_TEST=1`、`YANQIAN_DATA_DIR` 目录启动应用，避免修改真实任务或开机启动设置。
2. 完成任务后立即查看 Done，退出重启后检查内容和顺序；验证恢复、撤销、回收站。
3. 使用 Windows 10 的“显示桌面”按钮和 Win+D，多次切换后验证可点击、可编辑、无崩溃。验证任务栏、托盘、重复启动及快捷键恢复。
4. 原生中文输入法编辑后立即切页、隐藏和退出；重启核对最终文字。验证快捷键被其他软件占用时仍能通过托盘恢复。
5. 验证实际多显示器、拔掉副屏、分辨率与 DPI 变化后的窗口位置。
6. 验证 JSON 对话框取消、导入确认、损坏文件、恢复旧备份以及 Excel 文件内容。
7. 执行 `npm run electron:build`，在隔离数据目录完成安装包启动和上述核心流程冒烟检查。

完成这些检查并修复可能暴露的问题后，才能把 P0 标为全部完成。
